# Current action and halt source contracts

11 October 2026. Six official sources inspected by the bounded independent reviewer. No credentials, private API calls, vendor messages or operational data ingestion.

| Source | Useful contract | Remaining limit |
| --- | --- | --- |
| [Alpaca corporate actions REST](https://docs.alpaca.markets/us/reference/corporateactions-1) | Fixed data-host GET; process-date query, data_quality=all and next_page_token pagination. | Source gives no creation-time guarantee. Terminal response proves query capture, not complete effective/ex/pay-date coverage. |
| [Alpaca corporate-action SSE](https://docs.alpaca.markets/us/reference/subscribetocorporateactionseventssse) | Insert/update/delete events; inclusive replay by event ID; Last-Event-Id overrides since_id. | Replay retention and publication latency are unspecified; access unverified. It cannot repair upstream delays. |
| [Nasdaq halt RSS](https://www.nasdaqtrader.com/Trader.aspx?id=TradeHaltRSS) | Free; Nasdaq and other exchange-listed securities; updated once per trading-day minute. Poll no more than once/minute. | Polling is not a lossless event stream or sub-minute guarantee. |
| [Nasdaq halt code definitions](https://www.nasdaqtrader.com/Trader.aspx?id=TradeHaltCodes) | Distinct halt, quote-resumption and trade-resumption fields; T7 permits quotations while trading stays paused. | Resumption times are scheduled; reaching one does not prove actual resumption. |
| [Alpaca stock status stream](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data) | Symbol/status/reason/time/tape; CTA A/B halt2/resume3; UTP C/O H/P/Q/T distinguish halt/pause/quotation/trading resumption. | Subscription access, initial state, gap detection and reconnect continuity remain unverified. No sequence number documented. |
| [Alpaca feed definitions](https://docs.alpaca.markets/us/docs/historical-stock-data-1) | IEX is available without subscription and covers one exchange; SIP is consolidated. | IEX access does not establish action entitlement or complete market-wide status coverage. |

Next implementation may retain these observations and detect blockers. It must preserve unknown initial state, sequence/recovery gaps, stale observations, symbol/identity conflicts, unsupported events and late revisions. Empty actions, active/tradable assets, fresh quotes, scheduled resumptions and quote-only resumptions cannot create an unconditional current-clear result. A future native reader proves receipt provenance; complete source coverage and an accepted freshness basis remain separate.

Further official query evidence (11 October): [Nasdaq query examples](https://www.nasdaqtrader.com/snippets/tradehaltaccordion.html) say the default query returns halts initiated on the current halt day. Historical haltdate refers to the initial halt date; resumedate is distinct. Therefore an empty current-day query cannot exclude a still-active halt initiated earlier. The linked field-definition page gives display fields but not XML tag names; RSS parsing requires a retained original sample/schema. [Alpaca status schema](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data) has T,S,sc,sm,rc,rm,t,z; actual WebSocket messages are arrays. The next pure status qualifier must retain the original frame bytes, with source/tape-specific classification and no current-clear claim. No live RSS or authenticated stream was read.
