## Write clearly

Use [ASD-STE100](https://www.asd-ste100.org/) principles in all project text, including replies, documents, diagrams, reviews, and program messages.
These rules apply to all contributors and agents. Include them in instructions for agents that cannot read this file.

- Use common words, complete sentences, and active verbs.
- Give one instruction or idea per sentence. Limit instructions to 20 words and other sentences to 25 words.
- Put conditions before instructions. Name who does the action.
- Use one name for each thing. Explain necessary technical terms and abbreviations when first used.
- Keep exact file names, commands, code names, units, and results.
- State what happened, what it means, and what happens next.
- Check revised text before completion. Improve explanations you touch. Preserve evidence, quotations, and historical records.
- Claim full compliance only after checking the standard's rules and dictionary.
