# Four-stage reporting

17 October 2026. The owner approved reporting for mathematics, qualification, signals, and feedback.
The Hub stays read-only. Do not start the operational loop or change any operating gate.

Use a small reporting interface that a separately authorized program calls around its actual work.
Keep product source, installed packages, runtime journals, and frozen identities unchanged.
Write bounded reporting receipts outside the repository. The Hub only reads them.
Bind current activity to the actual project directory, process identity, and fresh heartbeat.
Expose fixed states, numeric progress, source times, and work type. Never expose task content or financial values.
Also display existing engineering job receipts for these stages, with their work type explicit.
No report means No report received. A stale heartbeat or missing process does not mean success.
Report completion is a producer's report. It is not financial acceptance or permission to continue the loop.
The reporting interface does not implement missing signal generation or automatic feedback.
