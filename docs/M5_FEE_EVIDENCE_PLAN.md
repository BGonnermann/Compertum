Implement one pure module, src/compertum/paper_fees.py. An immutable FeeSource holds up to 2 MiB original bytes, public HTTPS URL, media type and actual declared retrieval time. Captured-source provenance remains unverified by the pure object. A FeeSchedule binds one to four source fingerprints to a strict canonical declaration with UUID, explicit inclusive/exclusive declared date interval, USD/NMS_EQUITY, and up to four distinct fee components: SEC, TAF, CAT, COMMISSION. Each rule records charged BUY/SELL sides, SHARES or PRINCIPAL rate basis, bounded exact decimal rate, minimum, optional cap, separate limit and rounding units FILL/ORDER/ACCOUNT_DAY, and CEILING or HALF_UP cent rounding. Min/cap apply to each limit group, then limited amounts aggregate to the same or coarser rounding group before cent rounding; cent-aligned limits cannot be exceeded through rounding. All intervals and classifications are declared scenarios, never verified source interpretation.

A bounded immutable FeeBatch binds project hash, account alias, NY execution date and at most 128 distinct execution records (UUID execution/order IDs, frozen-watchlist symbol including SPY, BUY/SELL, original UTC time, exact positive quantity and price). An order cannot mix side/symbol. Fractional execution quantities are retained exactly; this does not authorize fractional orders. Preserve canonical original batch bytes. No cumulative-fill records or provider/native provenance is inferred.

Calculate every required fee component from exactly one effective schedule. Overlapping declarations are ambiguous even if rates match; absent, expired or conflicting components yield no complete declared total. Explicit non-charged sides yield a component zero supported by the declaration, not by a missing schedule. Aggregate per execution, order or account-day as declared, with dedicated Decimal context and exact arithmetic. Account-day groups include both sides and symbols where applicable; never round individual fills before an account-day sum. Results retain each billing group and declared subtotal, with actual billed total None, account applicability UNVERIFIED, daily fill completeness UNVERIFIED and false transport/financial authority. Immutable results reconstruct all calculations from retained source/schedule/batch objects; forged flags or amounts are rejected. No changes to simulation/provider_replay.py's 2023 scenario.
